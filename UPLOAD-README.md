# Manual upload package

Upload the contents of this folder to the repository root, preserving the folders:

- `apps-script/`
- `data/`
- `.github/workflows/`
- `scripts/`

Replace the repository's `index.html` and public template files with these versions.

## Important deletion

Delete this old public file from the repository if it still exists:

```text
Investor-Criteria-Form.html
```

It is intentionally not included in this package because it must be removed rather than replaced.

## Files that must be reviewed before publishing

- Complete identity and fee placeholders in `config.js`.
- Keep `analytics.enabled` set to `false` until deliberately configured.
- Do not add Sheet IDs, Drive folder IDs, API keys or personal data to `config.js`.
- Keep the Google Sheet and viewing-photo Drive folder private.
- Deploy `apps-script/AdminCode.gs` and `apps-script/Admin.html` as the private admin.
- Deploy `apps-script/AlertEndpointCode.gs` separately as the append-only public alert endpoint.

The `data/auction-stock.json` file was generated by the repository scraper and includes source/status metadata. Check its freshness before publishing.
